# Data

Full raw datasets and source PDFs are not committed (too large for git).
Small 100-row samples are in `samples/` so the schema and pipeline are
easy to inspect and test.

## Samples included
- `samples/Personal_Finance_Dataset_1_sample.csv`
- `samples/Daily_Household_Transactions_2_sample.csv`
- `samples/cleaned_finance_data_sample.csv`
- `samples/cleaned_household_data_sample.csv`
- `samples/Finance_data.csv`, `Original_data.csv`, UPI transaction CSVs (2021/2022) — secondary datasets, small enough to keep in full
